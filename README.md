# Shreekala Pandey — Brand Growth Strategist Portfolio

Next.js portfolio site built with Supabase, Tailwind CSS, Three.js, and custom animation components.

## Tech Stack
- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS
- Supabase (data + auth)
- Three.js / OGL (3D / WebGL)
- Motion / GSAP (animations)
- ShadCN UI

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Scripts
- `npm run dev` — Start development server
- `npm run build` — Production build
- `npm run start` — Start production server
